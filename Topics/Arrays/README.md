# Arrays

Arrays store elements in a contiguous sequence and provide fast index-based access.

### Key Concepts

* Traversal
* Searching
* Sorting
* Prefix Sum
* Kadane's Algorithm
* Two Pointers

### Common Complexity

* Access: `O(1)`
* Search: `O(n)`
* Insert/Delete: `O(n)`

### Practice

Focus on traversal, subarrays, prefix sums, and array manipulation.
